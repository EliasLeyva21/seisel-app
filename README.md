# Sistema Web para la Gestión del Mantenimiento Preventivo de Sistemas Contra Incendios

Proyecto desarrollado para SEISEL S.A.C.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Supabase
- Chart.js
- Git
- Azure Static Web Apps

## Funcionalidades

- Inicio de sesión
- Dashboard
- CRUD de Clientes
- CRUD de Equipos
- CRUD de Inspecciones
- CRUD de Órdenes
- Alertas automáticas
- Gráficos estadísticos

## Instalación

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Configurar `assets/js/config.js` con la URL y API Key de Supabase.
4. Ejecutar con Live Server.

## Despliegue

El proyecto está preparado para desplegarse en Azure Static Web Apps.
